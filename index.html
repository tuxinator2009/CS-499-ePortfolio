Professional Self-Assessment

This ePortfolio represents the culmination of my Bachelor of Science in Computer Science program at Southern New Hampshire University. It demonstrates the development of my skills in software engineering and design, algorithms and data structures, database development, security, technical communication, and the design of computing solutions that address practical problems.

Throughout the Computer Science program, I expanded my understanding of software development beyond implementing individual features. My coursework strengthened my ability to evaluate how the components of a system interact, identify trade-offs among possible solutions, design maintainable architectures, work with persistent data, evaluate algorithms, test software, and consider security throughout the development process. The program also reinforced the importance of communicating technical decisions clearly so that software can be understood, evaluated, and maintained by people other than its original developer.

The capstone project brought these areas together by requiring me to revisit an existing full-stack application, critically evaluate its design, and progressively improve it. Rather than treating software engineering, algorithms, databases, and security as isolated topics, the enhancement process demonstrated how decisions in one area affect the others. Changes to application architecture created clearer boundaries for later algorithmic and database functionality, while new functionality introduced additional requirements for validation, testing, authorization, and data protection.

Capstone Artifact

The primary artifact featured throughout this portfolio is Travlr Getaways, a full-stack web application originally created for CS 465: Full Stack Development. The application combines an Express and Node.js backend, MongoDB persistence through Mongoose, a customer-facing website, an Angular administrative interface, RESTful API communication, and JSON Web Token authentication.

I selected a single multifaceted artifact for all three enhancement categories so that the portfolio could demonstrate the progressive evolution of one software system. The original application provides a common baseline, while each enhancement addresses a different area of computer science and builds upon the improvements made during the previous stage.

1. Software Engineering & Design

The first enhancement restructures the application around clearer architectural boundaries and improves authentication, validation, error handling, defensive programming, and maintainability.

View Software Engineering Enhancement

2. Algorithms & Data Structures

The second enhancement expands trip discovery through search, filtering, relevance ranking, sorting, data processing, validation, and automated testing while considering the trade-offs involved in where data processing should occur.

View Algorithms & Data Structures Enhancement

3. Databases

The final enhancement extends the application with a reservation system incorporating MongoDB relationships, schema validation, historical booking data, indexing, aggregation reporting, ownership authorization, and role-based access control.

View Database Enhancement

Computer Science Program Outcomes

The artifacts, enhancements, narratives, code review, and professional self-assessment presented in this portfolio work together to demonstrate achievement of the five Computer Science program outcomes.

  1. Employ strategies for building collaborative environments that enable diverse audiences to support organizational decision making in the field of computer science.
  2. Design, develop, and deliver professional-quality oral, written, and visual communications that are coherent, technically sound, and appropriately adapted to specific audiences and contexts.
  3. Design and evaluate computing solutions that solve a given problem using algorithmic principles and computer science practices and standards appropriate to its solution while managing the trade-offs involved in design choices.
  4. Demonstrate an ability to use well-founded and innovative techniques, skills, and tools in computing practices for the purpose of implementing computer solutions that deliver value and accomplish industry-specific goals.
  5. Develop a security mindset that anticipates adversarial exploits in software architecture and designs to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of data and resources.
