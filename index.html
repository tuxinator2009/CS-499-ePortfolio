Professional Self-Assessment

This ePortfolio represents the culmination of my Bachelor of Science in Computer Science program at Southern New Hampshire University. It demonstrates the development of my skills in software engineering and design, algorithms and data structures, database development, security, technical communication, and the design of computing solutions that address practical problems.

Throughout the Computer Science program, I expanded my understanding of software development beyond implementing individual features. My coursework strengthened my ability to evaluate how the components of a system interact, identify trade-offs among possible solutions, design maintainable architectures, work with persistent data, evaluate algorithms, test software, and consider security throughout the development process. The program also reinforced the importance of communicating technical decisions clearly so that software can be understood, evaluated, and maintained by people other than its original developer.

The capstone project brought these areas together by requiring me to revisit an existing full-stack application, critically evaluate its design, and progressively improve it. Rather than treating software engineering, algorithms, databases, and security as isolated topics, the enhancement process demonstrated how decisions in one area affect the others. Changes to application architecture created clearer boundaries for later algorithmic and database functionality, while new functionality introduced additional requirements for validation, testing, authorization, and data protection.

Growth Throughout the Computer Science Program

My development as a computer science professional has also been shaped by experience that predates and extends beyond the projects represented in this portfolio. I entered the program with many years of programming experience, particularly with C and C++, but much of that experience had been developed independently. The Computer Science program gave me an opportunity to place that practical experience within a broader foundation of software engineering principles, development methodologies, algorithms, databases, security, testing, and system design. As a result, I leave the program not simply with additional programming languages or technologies, but with a stronger framework for evaluating why a particular solution is appropriate for a problem.

One of my strongest skills is breaking complex problems into smaller, understandable components. Throughout the program, I applied this approach across projects involving object-oriented programming, full-stack development, databases, graphics, software testing, and secure coding. Rather than beginning with a particular language or implementation, I tend to first identify the relationships among the components of a problem, determine the responsibilities each component should have, and then select the tools needed to implement the solution. This approach has become increasingly important as my projects have grown from individual programs into systems containing multiple interacting layers.

Collaboration and Communication

The program also strengthened my understanding of collaboration as more than multiple developers writing code for the same project. Effective collaboration requires software and documentation that allow other people to understand the reasoning behind technical decisions. Coursework involving software development lifecycles, requirements, design documentation, testing, and project evaluation reinforced the importance of communicating both what a system does and why it was designed in a particular way.

Communicating with stakeholders similarly requires adapting technical information to the needs of the audience. A developer may need implementation details, while a customer or project stakeholder is more interested in functionality, constraints, risks, and value. Written project documentation, design explanations, presentations, and the code review completed for this capstone required me to communicate technical decisions at different levels of abstraction. These experiences strengthened my ability to explain a computing solution without assuming that every audience shares the same technical background.

Algorithms and Data Structures

My work with algorithms and data structures reinforced the idea that producing the correct result is only one part of designing a computing solution. The organization of data and the algorithms used to process it affect performance, maintainability, scalability, and the kinds of functionality that can reasonably be provided. Throughout the program, I worked with common data structures and algorithmic techniques while learning to evaluate their trade-offs rather than simply selecting a solution because it works.

The algorithms enhancement represented in this portfolio applies that reasoning to a practical full-stack application. The original Travlr Getaways application retrieved an entire collection of trips without providing meaningful mechanisms for narrowing or ordering the results. I enhanced that behavior with search, filtering, sorting, and relevance ranking. The implementation required deciding which operations belonged in database queries and which were better performed through application-level processing. Automated tests were also added to verify price conversion, trip-duration parsing, filtering, ranking, and sorting behavior. This demonstrates not only the implementation of algorithms but the evaluation of where those algorithms belong within a larger system.

Software Engineering and Databases

Software engineering coursework expanded my focus from individual functions and classes to the architecture of entire applications. Maintainability becomes increasingly important as software grows, and clear separation of responsibilities makes systems easier to understand, test, modify, and secure. I have applied these principles both in coursework and in larger independent software projects developed outside the classroom.

Outside the program, I have also applied these skills to embedded systems and game-development projects involving constrained hardware, performance optimization, graphics, storage, and networked systems. These experiences reinforced the same problem-solving approach used throughout my coursework: understand the constraints first, decompose the problem, and select an implementation appropriate to the system.

Database development added another dimension to that systems perspective. Persistent data is not simply information that an application stores; its structure determines what the application can efficiently retrieve, validate, relate, and protect. My coursework provided experience with both relational and document-oriented approaches, including SQL and MongoDB. Through these projects, I developed a stronger understanding of schema design, validation, querying, indexing, relationships, and the interaction between the persistence layer and the rest of an application.

The database enhancement in this portfolio demonstrates that progression by extending Travlr Getaways beyond a simple trip catalog. The enhanced application introduces booking data and relationships among users, trips, and reservations. It also incorporates validation, calculated booking totals, access control, and administrative capabilities. This transformed the database from passive storage for displayed content into an active part of the application's business model.

Security Mindset

Security has become an increasingly important part of how I evaluate software. The program reinforced that security should not be treated as a feature added after an application is complete. Every boundary where data enters a system, crosses between components, or is retrieved by a user creates questions about trust, validation, authentication, authorization, and potential misuse.

This perspective influenced several of the capstone enhancements. Authentication middleware was reorganized so protected operations continue only after successful JWT verification, Angular route guards provide an additional client-side boundary for administrative functionality, and application errors are handled without unnecessarily exposing implementation details. The booking enhancement extends this principle from authentication to authorization: possessing a valid account does not automatically mean a user should be permitted to access another user's reservation. Ownership checks therefore protect resources according to the identity and privileges of the authenticated user.

Professional Direction

Completing the Computer Science program has also helped clarify my professional values. I value systems that are understandable, maintainable, and designed deliberately rather than solutions built around a particular technology simply because that technology is available. I am most comfortable working from the structure of a problem outward: understanding requirements, identifying relationships and constraints, evaluating possible approaches, and then implementing the solution with appropriate tools.

The program has therefore strengthened both my technical capabilities and my ability to continue learning independently. Technologies, frameworks, and programming languages will continue to change, but the underlying ability to analyze a problem, understand unfamiliar systems, evaluate trade-offs, communicate decisions, and learn the tools required for a solution is transferable. Completing this degree provides a formal foundation beneath the programming experience I brought into the program and gives me a broader range of skills that I can apply to future software projects and professional opportunities.

Portfolio Overview

The artifacts that follow demonstrate these abilities through the progressive enhancement of the Travlr Getaways full-stack web application. I intentionally used the same artifact across all three enhancement categories because doing so demonstrates how software engineering, algorithms, databases, and security interact within a single system rather than presenting them as unrelated technical exercises.

The Software Engineering and Design enhancement reorganizes the application around clearer architectural responsibilities, including controllers, services, repositories, authentication middleware, consistent error handling, and client-side route protection. The Algorithms and Data Structures enhancement introduces search, filtering, sorting, and ranking behavior, supported by automated tests. The Databases enhancement expands the application's data model through reservations and relationships among users and trips while adding validation, authorization, and application functionality built around that persistent data.

Together with the code review, these artifacts show the progression from evaluating an existing software system to identifying weaknesses, proposing improvements, implementing those improvements, testing their behavior, and reflecting on the resulting design. Collectively, the portfolio demonstrates my ability to approach computing problems as interconnected systems and represents the culmination of the knowledge and skills I developed throughout the Bachelor of Science in Computer Science program.

Capstone Artifact

The primary artifact featured throughout this portfolio is Travlr Getaways, a full-stack web application originally created for CS 465: Full Stack Development. The application combines an Express and Node.js backend, MongoDB persistence through Mongoose, a customer-facing website, an Angular administrative interface, RESTful API communication, and JSON Web Token authentication.

I selected a single multifaceted artifact for all three enhancement categories so that the portfolio could demonstrate the progressive evolution of one software system. The original application provides a common baseline, while each enhancement addresses a different area of computer science and builds upon the improvements made during the previous stage.

1. Software Engineering & Design

The first enhancement restructures the application around clearer architectural boundaries and improves authentication, validation, error handling, defensive programming, and maintainability.

View Software Engineering Enhancement

2. Algorithms & Data Structures

The second enhancement expands trip discovery through search, filtering, relevance ranking, sorting, data processing, validation, and automated testing while considering the trade-offs involved in where data processing should occur.

View Algorithms & Data Structures Enhancement

3. Databases

The final enhancement extends the application with a reservation system incorporating MongoDB relationships, schema validation, historical booking data, indexing, aggregation reporting, ownership authorization, and role-based access control.
